# Nexus VPN Mobile

VPN-клиент для Android с умной самообучающейся маршрутизацией (Smart Auto-Split Tunneling).
Мобильная версия NexusVPN Pro для компьютера: те же настройки и возможности, удобные для телефона.

**[Скачать последнюю версию](../../releases/latest)** — файл `Nexus-VPN-Mobile-….apk`.

## Установка

1. Откройте на телефоне страницу **Releases** и скачайте `Nexus-VPN-Mobile-….apk`.
2. Откройте скачанный файл. Android спросит, разрешить ли установку из этого источника — разрешите.
3. Запустите Nexus VPN Mobile → «Серверы» → скопируйте ссылку на подписку и нажмите **«Вставить из буфера»**.
4. Вернитесь на главную и нажмите на круг. При первом включении Android попросит разрешение на VPN.

Нужен Android 7 или новее, 64-битный телефон (практически все телефоны с 2017 года).

## Обновления

Приложение само проверяет новые версии в Releases этого репозитория («Обновления» → «Скачать и установить»).
Новая версия ставится поверх старой, настройки, подписки и изученное сохраняются.

## Три режима

- **Умная** — программа сама находит сайты и приложения, которые не открываются напрямую (блокировка,
  замедление, заглушка провайдера), проверяет их через VPN и запоминает. Остальное идёт напрямую на полной
  скорости. Плюс готовые базы: заблокированное в РФ, YouTube, Discord, Telegram, ИИ-сервисы, Meta, X.
- **Всё через VPN** — весь трафик телефона.
- **Своя** — только то, что вы выбрали сами: сайты, IP, подсети и приложения.

## Протоколы

VLESS (Reality, Vision, WS, gRPC, HTTP/2, HTTPUpgrade), VMess, Trojan, Shadowsocks, Hysteria2, TUIC,
WireGuard, AnyTLS, SOCKS, HTTP. Ядро — [sing-box](https://github.com/SagerNet/sing-box) 1.14.

Пока только на компьютере: XHTTP, AmneziaWG, OpenVPN и IKEv2. На телефоне такие серверы видны в списке
с пометкой и пропускаются.

## Если что-то не работает

- Ошибка при запуске показывается на экране — нажмите «Копировать» и пришлите текст.
- Если приложение закрылось, при следующем запуске появится окно с причиной.
- VPN отключается сам — «О программе» → «Разрешить работу в фоне» и включите «Постоянную VPN».

## Сборка

Каждое изменение в ветке `main` (в том числе файлы, загруженные через сайт GitHub) запускает
`.github/workflows/build.yml`: тесты → сборка ядра sing-box для Android (только в первый раз, ~15 минут,
потом из кэша) → сборка APK → новый релиз `v1.0.0.N`. Номер N растёт с каждой сборкой.

Версия задаётся в `app/src/main/python/nexusvpn/paths.py` (`APP_VERSION`).

### Свой ключ подписи

Без настроек APK подписывается ключом `nexusvpn.keystore` из репозитория. Чтобы подписывать своим ключом
(никто другой не сможет выпустить «обновление» вашего приложения), один раз создайте ключ:

```
keytool -genkeypair -keystore my.keystore -alias nexus -keyalg RSA -keysize 2048 -validity 36500
```

и добавьте в **Settings → Secrets and variables → Actions**:

| Секрет | Значение |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | содержимое `my.keystore` в base64 (`base64 -w0 my.keystore`) |
| `ANDROID_KEYSTORE_PASSWORD` | пароль хранилища |
| `ANDROID_KEY_ALIAS` | `nexus` |
| `ANDROID_KEY_PASSWORD` | пароль ключа |

Сделайте это до того, как раздадите приложение: при смене ключа приложение придётся удалить и поставить заново.

### Устройство

- `app/src/main/python/nexusvpn/` — ядро программы (то же, что в NexusVPN Pro для ПК): подписки, парсеры
  ссылок, сборка конфигурации sing-box, умная маршрутизация, переключение серверов без обрыва звонков.
- `app/src/main/python/nexus_android/` — адаптация для телефона: приложения вместо программ Windows, запуск
  ядра через VpnService, команды для экранов.
- `app/src/main/java/pro/nexusvpn/` — Android: VPN-служба (sing-box как библиотека libbox), экраны на Jetpack Compose.
- `tests/` — тесты: конфигурация для телефона проверяется настоящим sing-box.

Локально: Android SDK, JDK 17, Python 3.13, Go 1.26 и `gomobile` (команды — в `build.yml`), затем
`gradle :app:assembleRelease`.
